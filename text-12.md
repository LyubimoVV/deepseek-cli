# Персонализация ассистента

## Как могут отличаться ответы для разных профилей

Разные профили генерируют разные ответы на основе настроенных параметров:

**Стиль ответа:**
- Профиль "Разработчик" — техническая терминология, ссылки на документацию, примеры кода
- Профиль "Бизнес-аналитик" — фокус на KPI, метрики, бизнес-процессы
- Профиль "Новичок" — простые объяснения, пошаговые инструкции, без жаргона

**Формат вывода:**
- Профиль "Консоль" — краткие ответы, без форматирования
- Профиль "Markdown" — структурированные ответы с заголовками, списками, таблицами
- Профиль "Доклад" — развернутые ответы с введением, анализом и выводами

**Ограничения:**
- Профиль "Безопасность" — фильтрация опасных команд, предупреждения о рисках
- Профиль "Производительность" — приоритет эффективности кода
- Профиль "Читаемость" — акцент на понятность и документирование

## Что ассистент учитывает автоматически

Ассистент автоматически учитывает параметры активного профиля:

1. **История взаимодействий** — предыдущие вопросы и ответы для сохранения контекста диалога

2. **Настройки стиля** — тон коммуникации (формальный/неформальный), уровень детализации

3. **Форматирование** — предпочтительный формат вывода (текст, код, таблицы, списки)

4. **Ограничения** — максимальная длина ответа, запрещенные темы, стиль кода

5. **Предпочтения по языку** — язык ответа, смешанная терминология

6. **Контекст проекта** — структура проекта, использованные технологии, соглашения по коду
