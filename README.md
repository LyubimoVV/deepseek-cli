# DeepSeek CLI

Интерактивный CLI-клиент для DeepSeek API на Java 17.

## Требования

- Java 17 или выше
- Maven 3.6+
- API-ключ DeepSeek

## Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd deepseek-cli
```

### 2. Настройка API-ключа

Установите переменную окружения `DEEPSEEK_API_KEY`:

**Windows:**
```cmd
set DEEPSEEK_API_KEY=your_api_key_here
```

**Linux/macOS:**
```bash
export DEEPSEEK_API_KEY=your_api_key_here
```

## Запуск

### Простой способ (Windows)

```bash
run.bat
```

Этот файл автоматически соберет проект при необходимости.

### Ручной запуск

```bash
mvn clean package
java -jar target/deepseek-cli-1.0.0.jar
```

## Использование

После запуска вы увидите приглашение `>`. Введите сообщение и нажмите Enter для отправки обычного запроса.

### Команды

| Команда | Описание |
|---------|----------|
| `<сообщение>` | Обычный запрос без ограничений |
| `/limited <question>` | Ограниченный запрос (200 токенов, \n\n стоп) |
| `/mode <1\|2>` | Выбрать режим: 1 - Тестировщик, 2 - Обычный помощник |
| `/system` | Показать текущий системный промпт |
| `/limited_settings` | Показать настройки ограниченного режима |
| `/set <параметр> <значение>` | Изменить параметр ограниченного режима |
| `/clear` | Очистить историю диалога |
| `/help` | Показать справку по командам |
| `/exit` | Выход из приложения |

### Режимы работы

Доступны два режима работы:

1. **Тестировщик (Senior QA Engineer)** - Экспертные ответы по тестированию для джуниоров
2. **Обычный помощник (General Assistant)** - Универсальный помощник

Переключение между режимами:
```
> /mode 1
[OK] Режим изменен на: Тестировщик
[INFO] История диалога очищена

> /mode 2
[OK] Режим изменен на: Обычный помощник
[INFO] История диалога очищена
```

### Обычные и ограниченные запросы

- **Обычный запрос** - просто напишите сообщение и нажмите Enter
- **Ограниченный запрос** - используйте `/limited <вопрос>` для получения краткого ответа (до 200 токенов)

### Пример сессии

```
DeepSeek CLI - Тестирование форматов ответов
Введите сообщение и нажмите Enter.

> /mode 1
[OK] Режим изменен на: Тестировщик

> What is unit testing?
Думаю...

Юнит-тестирование — это метод тестирования программного обеспечения...
(подробный развернутый ответ)

> /limited What is integration testing?
[LIMITED] Ограниченный запрос (макс 200 токенов, \n\n стоп)...

[RESULT] Ограниченный ответ:
Краткий экспертный ответ до 200 токенов...

> /system
[SYSTEM PROMPT] Текущий системный промпт:
Ты senior тестировщик из Google с 10+ годами опыта...
Текущий режим: Тестировщик (Senior QA Engineer)

> /exit
До свидания!
```

### Настройка параметров ограниченного режима

Команда `/set` позволяет настроить параметры для `/limited` запросов:

```
> /limited_settings
[LIMITED SETTINGS] Настройки ограниченного режима:
Макс токенов: 200
Стоп-последовательности: [\n\n]
Текущий режим: Тестировщик (Senior QA Engineer)

> /set max_tokens 150
[OK] Максимум токенов установлен: 150

> /set stop "###,---"
[OK] Стоп-последовательности установлены: [###, ---]
```

Доступные параметры:
- `max_tokens` - максимальное количество токенов в ответе
- `stop` - стоп-последовательности (через запятую)

## Особенности

### Форматирование ответов

Все системные промпты настроены для вывода **только обычного текста** без использования:
- LaTeX разметки (`\(`, `\)`, `\[`, `\]`, `$`, `$$`)
- Markdown форматирования (звездочки, решетки)
- Специальных символов

Это обеспечивает корректное отображение в консоли.

### История диалога

Приложение сохраняет историю диалога между запросами. Для очистки истории используйте `/clear`.

При смене режима через `/mode` история автоматически очищается.

## Обработка ошибок

Приложение обрабатывает следующие типы ошибок:

- **API Error** — ошибки от DeepSeek API (неверный ключ, лимиты и т.д.)
- **Network Error** — проблемы с сетевым соединением
- **Timeout** — превышено время ожидания ответа (60 секунд)

Примеры ошибок:

```
> test question
Ошибка API (401): Unauthorized - проверьте API ключ

> test question
Ошибка: Request interrupted - проблемы с сетью
```

## Технические детали

- **HTTP клиент:** Java 11+ HttpClient
- **JSON сериализация:** Jackson 2.16.0
- **Таймауты:** 60 секунд на запрос
- **API endpoint:** https://api.deepseek.com/v1/chat/completions
- **Модель:** deepseek-chat
